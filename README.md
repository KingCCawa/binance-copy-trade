# 币安跟单（Binance Copy Trade）

按公开带单流水，在自己的币安合约账户里等比复刻带单员的仓位。

不用登录、不用 Cookie、不用浏览器：只读币安带单本的公开接口和本账户的
合约 API，不依赖任何非官方 SDK。

> ## 风险提示
>
> - 合约是杠杆交易，**可能亏掉全部本金**。本程序只是复刻别人的公开流水，
>   不构成投资建议，也不保证跟单结果与带单员一致。
> - `live` 模式会**真实下单**。第一次请先用 `dry-run` 跑够时间，确认
>   仓位数量、挂单价格、平仓比例都符合预期，再切真实账户。
> - 数据源是币安带单本的**非官方**接口，随时可能改动或限流；接口一改，
>   程序可能取不到数。这是已知风险，不是 bug。
> - 作者不承担任何资金损失。

---

## 它在做什么

币安「带单」名额满了就进不去官方跟单池，但带单本页面仍然公开每一笔
开仓/平仓。本程序把这串流水当作信号源：

```
带单员成交流水  →  按 (品种, 方向) 全量 FIFO 重放  →  他此刻该持多少
                                                      ↓
                              我的数量 = 他的数量 × (我的权益 ÷ 他的钱包余额)
                                                      ↓
                                          更优价限价单 / 容差价限价单
```

几个关键口径（改代码前必须知道）：

| 口径 | 定义 | 为什么 |
|---|---|---|
| 份额 | **数量等比**，不是名义等比 | 名义口径在限价偏离他成交价时会多算/少算数量 |
| 敞口分母 | 他的**钱包余额**（`marginBalance` 剔除未实现盈亏） | 用 `marginBalance` 会在他浮亏时放大我方仓位 |
| 盈亏 | 净值 = 钱包余额 + 浮动盈亏 | 只画余额的话，一次平仓会让曲线凭空下蹲 |
| 已实现盈亏 | 逐笔累加，不做钱包差分 | 差分会把用户手动划转算成盈利 |

## 快速开始

```bat
:: 1. 环境（Python >= 3.12）
py -3.12 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

:: 2. 配置
copy .env.example .env
::   填 BINANCE_API_KEY / BINANCE_API_SECRET
::   Key 只勾「读取」+「合约」，不要勾提现，也不要勾现货
::   （建议同时在币安后台绑定 IP 白名单）

:: 3. 启动
start-gui.bat
```

在「账号连接」页填 API Key 与 Secret，「跟单目标」填带单员 ID
（带单本链接末尾那串 19 位数字），然后：

1. 执行模式选 `dry-run`，点「开始轮询」，让它跑一段时间；
2. 到「跟单盈亏 → 仓位对账」核对「应开 / 已跟 / 待补差额」；
3. 到「跟单盈亏 → 概览」看净值曲线、收益率与回撤是否符合预期；
4. 确认无误后，再切 `testnet` 试，最后才切 `live`。

### 三种执行模式

| 模式 | 下单 | 数据来源 | 用途 |
|---|---|---|---|
| `dry-run` | 内存模拟撮合，不联网下单 | 真实带单员流水 | 验证仓位口径。限价单只有标记价穿到限价才成交 |
| `testnet` | 币安测试网 | 真实带单员流水 | 验证下单链路。测试网 Key 与实盘不通用 |
| `live` | 币安实盘合约 | 真实带单员流水 | 真钱，慎用 |

盈亏账本按 `mode` 分表存放，切模式不会串数据。

## 界面

七个主页签：账号连接 / 成交事件 / 未成交挂单 / 事件日志 / 跟单盈亏 /
操作播报 / 运行配置。

- **跟单盈亏**：净值曲线、收益率/回撤/带单员盈亏概览、当前持仓浮盈，
  以及「概览 / 交易员仓位 / 仓位对账」三个子页。数据落在 `state.db`。
  点「重算 / 清空」会清除当前模式的盈亏账本并从零重新记录。
- **操作播报**：带单员每笔动作的文字播报；只播报接口真给得出的字段。
- **运行配置**：执行模式、涨跌配色、界面语言、轮询与开机自启等。

### 切换语言

在「运行配置 → 界面语言」选择 `中文` 或 `English`，点「保存并连接」
即时生效，并写入 `gui-config.json` 的 `language` 键（`zh` / `en`）。
翻译由 `i18n.py` 在运行时应用到控件文本，不改动业务逻辑。

## 已知限制

- 带单员的**杠杆、保证金**公开接口不给，界面与播报都不显示，不猜测。
- 我方平仓价拿不到交易所成交均价，盈亏账本按平仓时刻标记价估算，
  误差来自滑点。
- 手续费与资金费没有单独记账：浮盈取交易所的 `unRealizedProfit`（含
  资金费），已实现里不含手续费明细。
- 历史成交窗口有限（最近若干百条）。极老的仓位滑出窗口后，平仓比例
  会退化为整仓平 —— 刻意的安全兜底。

## 自检与回归

```bat
py -3.12 run_all.py            :: 常规全量回归
py -3.12 run_all.py --full     :: 追加联网/回放项（未配置凭证时标 SKIP）
py -3.12 gui.py --selftest     :: 界面断言
py -3.12 copy_engine.py --selftest  :: 引擎 56 个场景
```

改完代码至少要跑 `run_all.py`。全绿才算完成，不要用「应该没问题」结案。

## 目录

| 文件 | 职责 |
|---|---|
| `gui.py` | 界面与线程编排（PySide6），不含跟单判定 |
| `copy_engine.py` | 事件流引擎：去重、挂单对账、幽灵单红线、对账补差 |
| `position_ledger.py` | 全量事件 FIFO 重放：存活批次、平前持仓、累计量 |
| `feed.py` | 中文流水解析、`Rule`、入场价单一真源 |
| `api_feed.py` | 带单本公开接口、聚合、标记价 |
| `net.py` | 币安 HTTP 双通道（直连 / 代理）+ 退避重试 |
| `account.py` | 只读账户自检 |
| `better_executor.py` | 把市价入场改成限价入场 |
| `pnl_tracker.py` | 盈亏口径（纯函数） |
| `sim_portfolio.py` | 离线等比重放（仓位管理页的数据源） |
| `state_store.py` | SQLite 持久化：事件水位 / 挂单 / 盈亏账本 |
| `theme_qss.py` | 主题与 QSS |
| `i18n.py` | 界面中英翻译层（运行时应用到控件文本） |
| `run_all.py` | 回归聚合器 |

## 配置与隐私

- `.env`（API 凭证）、`gui-config.json`（带单员 ID 与个人偏好）、
  `state.db`（成交与盈亏账本）、`logs/` 全部在 `.gitignore` 里，**不入库**。
- 源码里的带单员 ID 是占位值 `1234567890123456789`，必须自己换成真实的。
- 提交 issue 前请先删掉日志里的带单员 ID 与账户余额。
